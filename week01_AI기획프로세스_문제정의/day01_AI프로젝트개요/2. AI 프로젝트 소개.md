# AI 프로젝트 소개 
- 프로젝트명: 건강한하루
- AI 기반 건강기능식품 쇼핑몰 기획 프로젝트

---
## 프로젝트 목표

사용자가
- 자신의 건강 상태에 맞는 건강기능식품을 쉽게 찾고
- AI의 도움을 받아 제품을 추천받으며
- 올바른 복용 정보를 확인할 수 있는

AI 서비스를 기획합니다.

---
## 프로젝트에서 구현할 주요 기능
- 건강기능식품 검색
- 상품 상세 조회
- AI 맞춤 상품 추천
- AI 영양 상담

---
## AI 프로젝트 일정 
> 실습 시간을 이용해서 "건강한하루" 쇼핑몰을 구현할 예정 

| 주차 | 학습 주제 | 주요 산출물 |
|------|----------|------------|
| 1주차 | 문제 정의 | 문제 정의서, 시장조사서, 요구사항 정의서 |
| 2주차 | 데이터 정의 | 데이터 정의서, ERD, API 정의서 |
| 3주차 | 서비스 설계 | IA, User Flow, 화면설계서(Wireframe) |
| 4주차 | AI 기능 설계 | AI 기능 정의서, 프롬프트 설계서, Agent Workflow |
| 5주차 | RAG 서비스 설계 | RAG 서비스 설계서, RAG 아키텍처 문서 |
| 6주차 | 서비스 검증 및 테스트 | 테스트 시나리오, AI 응답 정책(Guardrail), 서비스 개선안 |

---
# AI 기획자가 가장 많이 하는 질문

프로젝트를 진행하면서 항상 아래 질문을 스스로 던져야 합니다.
- 어떤 문제를 해결하려는가?
- 이 문제를 AI로 해결할 가치가 있는가?
- 사용자에게 어떤 가치를 제공하는가?
- 어떤 데이터가 필요한가?
- AI는 어떤 역할을 수행하는가?
- 어떻게 검증할 것인가?
