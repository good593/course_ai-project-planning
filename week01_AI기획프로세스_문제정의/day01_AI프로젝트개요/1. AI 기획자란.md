# AI 기획자란?
> AI 기술을 활용하여 사용자의 문제를 해결하는 서비스를 기획하고 설계하는 사람

AI 기획자는 AI 모델을 직접 개발하는 사람이 아니라,
- `"어떤 문제를 AI로 해결할 수 있는지 정의하고, AI가 실제 서비스에서 가치를 만들 수 있도록 설계하는 역할"`을 담당합니다.
- `사용자의 문제를 정의하고, AI 기술과 데이터를 활용하여 이를 해결하는 서비스를 설계하며, 개발자·디자이너·데이터 전문가와 협업해 AI 서비스를 현실로 만드는 사람`입니다.

---
## 쉽게 이해하기

예를 들어,

**사용자가**

> "여행 계획을 쉽게 짜고 싶다."

라고 한다면,

---
**AI 기획자는**
- 어떤 사용자인가?
- 무엇이 불편한가?
- AI가 무엇을 대신해줄 수 있는가?
- 어떤 데이터를 사용할 것인가?
- 어떤 화면으로 제공할 것인가?
- 결과를 어떻게 보여줄 것인가?

를 설계합니다.

> 개발자는 이후 이를 구현합니다.

---
## AI 기획자의 핵심 역량
- 문제를 발견하는 능력
- 사용자 관점에서 생각하는 능력
- AI 기술의 활용 가능성을 판단하는 능력
- 데이터를 이해하는 능력
- AI 기능을 서비스로 설계하는 능력
- 다양한 직군과 협업하는 커뮤니케이션 능력
- AI 결과를 지속적으로 평가하고 개선하는 능력

---
## AI 기획자의 위치
> AI 기획자는 사용자와 AI 기술을 연결하는 역할을 수행합니다.

```
┌─────────┐   ┌──────────┐   ┌───────────────────────┐   ┌──────────────┐   ┌─────────────┐
│ 사용자  │ → │ 문제발견 │ → │      AI 기획자        │ → │   AI 개발자  │ → │ 서비스 출시 │
└─────────┘   └──────────┘   │───────────────────────│   └──────────────┘   └─────────────┘
                             │ • 문제 정의           │ 
                             │ • 서비스 설계         │
                             │ • 데이터 정의         │
                             │ • AI 기능 정의        │
                             └───────────────────────┘
```

---
## AI 기획자의 핵심 역할 

---
### 1. 문제 정의 (Problem Definition)
AI보다 먼저

> "무슨 문제를 해결할 것인가?"

를 정의해야 합니다.

```
예) AI 챗봇 만들자(X)

↓

고객 문의 응답 시간이 길다.(O)

↓

AI 챗봇으로 응답 시간을 줄이자.
```

---
### 2. 사용자 분석 
누가 사용하는가?
- 누구를 위한 서비스인가?
- 어떤 상황에서 사용하는가?
- 무엇이 불편한가?


예) 여행 플랫폼이라면
- 혼자 여행
- 가족 여행
- 커플 여행

필요한 기능이 모두 다릅니다.

---
### 3. AI 활용 가능성 판단
> 모든 문제를 AI가 해결하는 것은 아닙니다.

AI를 사용하는 것이 더 좋은지, 기존 프로그램으로 충분한지를 판단해야 합니다.

```
예) 자동 로그인
→ AI 필요 없음

여행 일정 추천
→ AI 활용 가능

음성 상담
→ AI 활용 가능
```

---
### 4. 데이터 정의
> AI는 데이터를 먹고 동작합니다.

기획자는
- 어떤 데이터가 필요한가?
- 어디에서 가져오는가?
- 품질은 충분한가?

를 정의합니다.

```
예) 여행 추천

필요 데이터
- 관광지
- 음식점
- 숙소
...
```

---
### 5. AI 기능 설계
> AI가 무엇을 할 것인지 정의합니다.

```
예) 여행 서비스
AI 기능
- 일정 생성
- 여행 추천
- 리뷰 요약
- 맛집 추천
- 여행 일정 수정
- 번역
- 음성 안내
```

---
### 6. 서비스 설계 (UX/UI)
> AI 결과를 사용자가 이해하기 쉽게 보여줘야 합니다.

예) 단순히
```
추천 결과 
```
보다 
```
추천 이유

✔ 비 오는 날 추천
✔ 가족 여행에 적합
✔ 평점 4.8
```
처럼 설명 가능해야 합니다.

---
### 7. 개발자와 협업

AI 기획자는
- 개발자
- 디자이너
- 데이터 분석가
- AI 엔지니어

사이에서 의사소통을 담당합니다.

---
### 8. 서비스 검증 및 개선

서비스를 출시한 후에도
- 정확도
- 만족도
- 오류
- 사용자 의견

을 분석하여 개선합니다.

## AI 기획자가 만드는 주요 산출물

| 산출물               | 설명             |
| ----------------- | -------------- |
| 문제 정의서            | 해결하려는 문제를 정의   |
| 요구사항 정의서          | 필요한 기능 정리      |
| 사용자 시나리오          | 사용 흐름 정의       |
| User Story        | 사용자 관점의 요구사항   |

---
| 산출물               | 설명             |
| ----------------- | -------------- |
| 화면 설계서(Wireframe) | 화면 구성          |
| 데이터 정의서           | 필요한 데이터 정의     |
| AI 기능 정의서         | AI가 수행할 기능 정의  |
| 프롬프트 설계서          | LLM 입력/출력 설계   |
| API 명세서           | 시스템 간 인터페이스 정의 |
| 테스트 시나리오          | 기능 검증 계획       |
| 서비스 개선안           | 운영 결과 기반 개선 계획 |

---
## AI 기획자가 알아야 하는 분야
핵심은 모델을 직접 개발하는 것이 아니라, AI를 서비스에 효과적으로 적용하는 능력입니다.

| 분야                 | 필요한 수준 |
| ------------------ | ------ |
| AI 개념              | ★★★★★  |
| LLM                | ★★★★★  |
| Prompt Engineering | ★★★★★  |
| 데이터 이해             | ★★★★☆  |

---
| 분야                 | 필요한 수준 |
| ------------------ | ------ |
| API                | ★★★★☆  |
| UX/UI              | ★★★★☆  |
| 기획 방법론             | ★★★★★  |
| 프로젝트 관리            | ★★★★☆  |
| 통계                 | ★★★☆☆  |
| Python             | ★★☆☆☆  |
| SQL                | ★★★☆☆  |
| 머신러닝 모델 개발         | ★☆☆☆☆  |

---
## AI 기획자와 AI 개발자의 차이

| 구분     | AI 기획자                   | AI 개발자            |
| ------ | ------------------------ | ----------------- |
| 목적     | 문제 해결과 서비스 설계            | AI 기능 구현          |
| 관심사    | 사용자, 비즈니스, 서비스           | 모델, 성능, 코드        |
| 주요 업무  | 요구사항 정의, AI 기능 설계, UX 기획 | 모델 개발, API 구현, 배포 |
| 주요 산출물 | 기획서, 요구사항, 화면 설계, 프롬프트   | 코드, 모델, API, 시스템  |
| 핵심 질문  | "무엇을 만들 것인가?"            | "어떻게 만들 것인가?"     |
