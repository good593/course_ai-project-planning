## [인증키](https://www.foodsafetykorea.go.kr/api/howToUseApi.do?menu_grp=MENU_GRP34&menu_no=687)
인증키(API Key)는 API 요청을 보낸 사용자를 식별하고 서비스 이용 권한과 호출량을 관리하기 위한 고유한 문자열입니다.

> 쉽게 말하면, 서비스를 이용할 수 있는 출입증이라고 생각하면 됩니다.

---
![w:900](./img/image-8.png)

---
### 왜 필요한가? 

| 목적     | 설명               |
| ------ | ---------------- |
| 사용자 식별 | 누가 API를 사용하는지 확인 |
| 보안     | 허가된 사용자만 접근 가능   |
| 사용량 관리 | 하루 호출 횟수 제한 등 적용 |
| 운영 관리 | 과도한 호출을 제한해 안정적으로 서비스 |

> 인증키는 소스 코드, Git 저장소, 화면 캡처, 노트북 출력에 노출하지 않습니다. 실습에서는 `.env` 파일에 저장하고 `.gitignore`에 등록합니다.
